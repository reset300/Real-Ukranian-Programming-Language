# Keywords and Operators

| Token | Purpose |
|---|---|
| `мінливе` | declare a mutable variable |
| `стає` | assignment |
| `позаяк` | if |
| `одначе` | else / part of else-if |
| `допоки` | while |
| `зачин` | begin block |
| `край` | end block |
| `авжеж` | boolean true |
| `ані` | boolean false |
| `вивести` | output |
| `додати` | addition |
| `відняти` | subtraction |
| `помножити` | multiplication |
| `поділити` | division |
| `остача` | remainder |
| `дорівнює` | equality |
| `недорівнює` | inequality |
| `перевищує` | greater than |
| `менше` | less than |
| `щонайменше` | greater than or equal |
| `щонайбільше` | less than or equal |
| `і` | logical AND |
| `або` | logical OR |
| `не` | logical NOT |
