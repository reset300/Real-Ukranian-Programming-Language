# Control Flow

## If

`позаяк` begins a conditional branch.

```text
позаяк число перевищує 10
зачин
    вивести("велике")
край
```

## Else

`одначе` begins the alternative branch.

```text
позаяк число перевищує 10
зачин
    вивести("велике")
край
одначе
зачин
    вивести("мале")
край
```

## Else-if

Else-if is written as `одначе позаяк`.

```text
позаяк число перевищує 10
зачин
    вивести("велике")
край
одначе позаяк число дорівнює 10
зачин
    вивести("десять")
край
одначе
зачин
    вивести("мале")
край
```

## While

`допоки` repeats a block while its condition is true.

```text
допоки число менше 10
зачин
    число стає число додати 1
край
```
