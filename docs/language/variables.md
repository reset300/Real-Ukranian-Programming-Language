# Variables

A mutable variable is introduced with `мінливе`.

```text
мінливе число стає 10
```

General form:

```text
мінливе <name> стає <expression>
```

To change an existing variable, omit `мінливе`:

```text
число стає 25
```

The current interpreter supports integers, strings, and booleans.

```text
мінливе число стає 42
мінливе текст стає "Привіт"
мінливе готово стає авжеж
```

Boolean literals are `авжеж` and `ані`.
