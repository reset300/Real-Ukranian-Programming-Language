# Expressions

Most operators are words.

## Arithmetic

| Operator | Meaning |
|---|---|
| `додати` | addition |
| `відняти` | subtraction |
| `помножити` | multiplication |
| `поділити` | integer division |
| `остача` | remainder |

Examples:

```text
10 додати 5
20 відняти 3
4 помножити 8
20 поділити 4
17 остача 5
```

## Equality

```text
дорівнює
недорівнює
```

## Ordering

| Operator | Meaning |
|---|---|
| `перевищує` | greater than |
| `менше` | less than |
| `щонайменше` | greater than or equal |
| `щонайбільше` | less than or equal |

## Boolean logic

```text
і
або
не
```

## Precedence

From highest to lowest:

1. parentheses
2. `не`
3. `помножити`, `поділити`, `остача`
4. `додати`, `відняти`
5. ordering
6. equality
7. `і`
8. `або`
